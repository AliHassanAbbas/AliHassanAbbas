# Ali Hassan Abbas

### AI Researcher · PyTorch Specialist · Deep Learning Engineer

I build and study deep-learning systems from first principles, with a focus on understanding the mathematics, implementing architectures in PyTorch, and making complex AI concepts accessible through practical teaching.

My work spans foundational neural networks, sequence models, Transformers, computer vision, generative models, and multimodal learning.

- **Research interests:** Deep learning architectures, efficient training, computer vision, NLP, generative AI, and multimodal models.
- **Engineering focus:** PyTorch, model implementation, training and evaluation workflows, and reproducible experimentation.
- **Teaching:** Practical, first-principles AI and PyTorch education.
